Cataloging assistants

Enter a Library of Congress Control Number. The record is pulled from id.loc.gov and three assistants run at once: subject headings from LC's catalog neighbours, a full LC call number built from the classification schedules and the shelflisting manual, and LCNAF links for the record's unlinked contributors. Results stream in as each one finishes.
