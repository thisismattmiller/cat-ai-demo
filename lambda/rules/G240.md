## Applies when

- The 1XX is a society (club, fraternity, lodge, association) or the work is about a society, and the class number is in class A (Societies Table applies to newly established societies).
- The society has already been established in the shelflist (any class) using the Societies Table, the Nine Number Table, or the Three Number Table: continue that table.
- A society not yet established is to be classed in B-Z: use G 220 (corporate bodies), not this chapter.
- In subclass AS, the form caption says the society should be Cuttered by place.

## Rules

1. [sec. 1] **Societies Table.** Apply the Societies Table (Table A4) to any newly established society classed in class A. The society gets a Cutter number `.x`; its publications and works about it are then arranged within `.x` by the table (official serials `.xA1-4`, subdivided by initial letter of the title; official monographs `.xA5-7`; nonofficial publications, i.e. works about the society, `.xA8-Z` by author).
2. [sec. 1] **AS subclass, Cuttered by place.** In the AS subclass, when the form caption indicates that the society should be Cuttered by place, Cutter for the place, use a digit to represent the society, and double Cutter using the Societies Table (e.g., Berlin `.B47` + digit `6` for the society = `AS182.B476`, then `A36` for an official serial, `A65 1977` for an official monograph, `S58 1981` for a nonofficial work by Smith).
3. [sec. 2.a] **Previously existing societies classed in A-Z.** Determine whether a guide card in the card shelflist has already been set up, and continue any special provisions shown there.
4. [sec. 2.b] If it is inconvenient to consult the guide cards, determine whether the Societies Table (class A only), the Nine Number Table, or the Three Number Table has been used and continue to apply that table.
5. [sec. 2.c] If the society has not been established, and it is to be classed in classes B-Z, follow the provisions of the corporate bodies instruction sheet (cf. G 220). If the society has not been established, and it is to be classed in class A, apply the Societies Table (sec. 1).

## Tables

SOCIETIES TABLE (Table A4) [sec. 1]. Use this table for any society newly established in Class A. In the AS subclass, when the form caption indicates that the society should be Cuttered by place, Cutter for the place, use a digit to represent the society, and double Cutter using this table.

| Range | Meaning |
|---|---|
| .x | Cutter number for society |
| .xA1-4 | Official serials |
| .xA1-.xA29 | Titles beginning A-K |
| .xA3-.xA39 | Titles beginning L-Q |
| .xA4-.xA49 | Titles beginning R-Z |
| .xA5-7 | Official monographs |
| .xA8-Z | Nonofficial publications. By author, A-Z |

NINE NUMBER TABLE [sec. 2]. Note: The Library of Congress no longer uses this table except for societies and institutions already established in this class.

| Number | Meaning |
|---|---|
| (1) | Proceedings and transactions |
| (2) | Collections: Bulletins, contributions, memoirs, etc. |
| (3) | Periodicals. Yearbooks |
| (4) | Annual reports |
| (4.5) | Other reports (nonserial) |
| (5) | Congresses and conferences. Expositions. |
| (6) | Constitution and bylaws |
| (7) | Directories. Lists of members |
| (8) | History and biography. Handbooks. For handbooks issued annually, see (2), (3), (4), or (7), as the case may be |
| (9) | Addresses, essays, lectures |
| (9.9) | Miscellaneous printed matter: Announcements, programs, etc. |

THREE NUMBER TABLE [sec. 2]. Note: The Library of Congress no longer uses this table except for societies and institutions already established in this class.

| Number | Meaning |
|---|---|
| .x | Cutter number for society |
| (1) .x-19 | Serial publications |
| (2) .x2-29 | Official monographs |
| (3) .x3A-Z | Nonofficial publications. By author, A-Z |

## Examples

Society in class A (AM1, Cutter .M87 for Museum Association): official serial in .xA1-4, title beginning M (L-Q range .xA3-.xA39) [sec. 1]:

```
Main entry:  Museum Association.
Title:  Monthly bulletin ...

050 00 $a AM1.M87 $b A25
```

Official monograph in .xA5-7, with date [sec. 1]:

```
Main entry:  Museum Association.
Title/date:   The annual history of the Museum ... 1963.

050 00 $a AM1.M87 $b A53 1963
```

Nonofficial publication (work about the society) in .xA8-Z, by author, with date [sec. 1]:

```
Main entry:  Alexander, Edward P. (Edward Porter), 1907-2003
Title/date:  Museum Association in motion.  1964.
Subject heading:  Museum Association.

050 00 $a AM1.M87 $b A85 1964
```

AS subclass, Cuttered by place (Berlin .B47) with a digit for the society (.B476), then the Societies Table as the second Cutter [sec. 1]:

```
Main entry:  Orden pour le Mérite für Wissenschaften und Künste.
Title:  Reden und Gedenkworte ...

050 00 $a AS182.B476 $b A36

Main entry:  Orden pour le Merité für Wissenschaften und Künste.
Title/date:  Orden pour le Merité für ... 1977.

050 00 $a AS182.B476 $b A65 1977

Main entry:  Smith, Robert E.
Title/date:  A history of Orden pour ... 1981
Subject heading:  Orden pour le Merité für Wissenschaften und ...

050 00 $a AS182.B476 $b S58 1981
```

## Pitfalls

- The Societies Table is for class A only. Societies newly classed in B-Z follow G 220 (one Cutter for the body, date, work letters), not this table [sec. 2.c].
- The Nine Number Table and Three Number Table are legacy: apply them only where a society or institution is already established with them; never start a new society on them [sec. 2].
- Within the Societies Table, official serials are subarranged by the first letter of the title into three bands (A-K, L-Q, R-Z), not by a simple successive letter.
- The society's own official publications fall in .xA1-7; the work of an outside author *about* the society falls in .xA8-Z under the author's name.
- In the manual's examples, official monographs and nonofficial works carry the publication date after the second Cutter; official serials carry no date.
