## Applies when

- Every call number, at the final step: writing the call number as an 050 field string with the correct indicators, $a/$b split, spacing and punctuation.
- The class number contains an internal date (e.g. KFG401 1983 .A6), the call number has no Cutter (date only), begins with CS71, carries volume numbering, or has alternate class numbers.

## Rules

1. **050 Library of Congress Call Number** [sec. 1]. The field has two indicator positions: the first contains a value that indicates whether or not LC holds the item under this call number; the second contains a value indicating the source assigning the call number. The call number itself has two parts, the classification number and the item number. Alternate classification numbers may be supplied.
   - `$a` Classification number
   - `$b` Item number
   - `$a` Alternate classification number
   - `050 00` — Assigned by LC. Since about mid-1999 second-position value "0" (Assigned by LC) has been used in all instances of records issued by LC containing a Library of Congress call number.
   - `050 04` — Assigned by an agency other than LC (second-position value "4"; prior to about mid-1999 retained in certain records created by NCCP or PCC participants or reflecting copy cataloging).
   - `050 10` — First-position value "1" indicates the item is not in LC or is not in LC under this number.

2. **Placement of the delimiter indicating subfield $b** [sec. 3].
   - a. **Words** [sec. 3.a]. When the call number field consists only of a class number (a word; letters followed by numbers, possibly including a period and also a space), no subfield $b is used.
   - b. **Cutter numbers** [sec. 3.b]. The delimiter for the item number ($b) precedes the last capital letter except when the last capital letter is preceded by a period, in which case the $b precedes the period. So a single Cutter goes in $b with its period (`$b .H2 1986`); with double Cutters the first (subject) Cutter stays in $a with its period and $b begins at the second Cutter's capital letter with no period (`$a TC506.H3 $b L7 1986`).
   - c. **CS71** [sec. 3.c]. If the call number begins with CS71, subfield $b contains the date.
   - d. **No Cutter number** [sec. 3.d]. If the class number is followed by a date but no Cutter number, the date is in subfield $b.
   - e. **Volume numbering** [sec. 3.e]. If the call number is followed by volume numbering that includes uppercase letters, these letters are ignored in locating the last capital letter.

3. **Dates within classification numbers** [sec. 4]. When a date is used internally, set off the date by preceding and following it with a single space.
   - Exception: If the schedule provides an instruction to append the date to the classification number, do not use a blank space before the date.

4. **Alternate numbers** [sec. 5]. Alternate numbers appear in a second $a subfield, after $b. More than one alternate may be given, each in its own $a.

## Examples

Class number that is a word only; no $b [sec. 3.a]:

```
050 00 $a LAW
```

Single Cutters: $b precedes the period before the last capital letter [sec. 3.b]:

```
050 00 $a TX536 $b .H2 1986
050 00 $a PN3329 $b .H74 1971
```

Double Cutters: $b precedes the last capital letter; the first Cutter and its period stay in $a [sec. 3.b]:

```
050 00 $a TC506.H3 $b L7 1986
```

Call number beginning with CS71: $b contains the date [sec. 3.c]:

```
050 00 $a CS71.B118 $b 1974
```

Class number followed by a date but no Cutter: the date is in $b [sec. 3.d]:

```
050 00 $a JX1989.5 $b 1944 IXb
```

Volume numbering with uppercase letters (Bd.) ignored when locating the last capital letter [sec. 3.e]:

```
050 00 $a DD3 $b .M83 Bd. 30
```

Date used internally in the classification number, set off by a single space before and after [sec. 4]:

```
050 00 $a KFG401 1983 .A6 $b H55 1994
050 00 $a HV600 1988 .A75 $b K37 1990
050 00 $a HD5329.T72 1974 $b M622 1977
```

Exception: schedule instructs that the date be appended to the class number, so no space before the date [sec. 4]:

```
In classification schedule:

KKA985.5<date>  Individual codes
                Arrange chronologically by appending the four-digit
                year of original enactment or revision of the code to the
                number KKA985.5 and deleting any trailing zeros

Formulation of call number:

050 00 $a KK985.51896 $b .A52 1995
```

Alternate numbers in a second $a subfield [sec. 5]:

```
050 00 $a DS136.6 $b .H38 1986 $a D106
050 00 $a Z5815.B5 $b P53 1985 $a LA551
050 00 $a Z8061 $b .K38 1986 $a Z8651 $a D803   [two alternate call numbers]
050 00 $a DD3 $b .M83 Bd. 30, etc. $a Z723
```

## Pitfalls

- The $b split is mechanical: find the last capital letter (ignoring uppercase letters in volume designations such as "Bd."); if a period immediately precedes it, $b starts at that period, otherwise at the letter [sec. 3.b, 3.e].
- A class number that already includes a schedule Cutter keeps that Cutter, with its period, inside $a; only the main-entry Cutter goes in $b, and it has no leading period [sec. 3.b].
- Internal dates get a single space on both sides (`KFG401 1983 .A6`), except when the schedule says to *append* the date to the number, where the year is run on with no space (`KK985.51896`) [sec. 4]. The printed example reads `KK985.51896` although the schedule excerpt it illustrates is `KKA985.5<date>`; quoted as printed.
- When there is no Cutter at all, the date alone is $b (`$a JX1989.5 $b 1944 IXb`); for CS71 the date is $b even though a Cutter is present in $a [sec. 3.c, 3.d].
- Alternate class numbers go in additional $a subfields after $b, never in $b [sec. 5].
