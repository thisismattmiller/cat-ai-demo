## Applies when
- The class number (or a table applied to it) carries the form caption "By state, A-Z" or "By province, A-Z", so a Cutter for a U.S. state or a Canadian province must be supplied.
- A state or province Cutter is being assigned in a given class for the first time, or must be reconciled with Cutters already established there.

## Rules
1. Existing Cutter numbers. If a Cutter number for a state or province has been used in the shelflist or established in the classification schedule, use that number even if it is in conflict with the number in the states and provinces table. [sec. 1]
2. New Cutter numbers. If a Cutter number for a specific state or province is being applied for the first time in a particular class, and there is no conflict with adjacent Cutter numbers, use the Cutter number indicated in the states and provinces table. If a conflict exists with adjacent Cutter numbers, continue the existing Cutter arrangement, adjusting the new Cutter to maintain the proper arrangement. [sec. 2]
3. The table is applied to new entries in the shelflist when the form caption reads By state, A-Z, or By province, A-Z, provided that there is no conflict with existing entries. [Background]

## Examples
The chapter contains no worked call-number examples; the tables themselves are the example set.

## Pitfalls
- The tables never override the shelflist: an existing Cutter for the same state or province in the same class wins even when it conflicts with the table. [sec. 1]
- When the table's Cutter would collide with or misfile against adjacent Cutters already in the class, adjust the new Cutter to keep the arrangement rather than forcing the table value. [sec. 2]
- District of Columbia is not a separate entry; it is Cuttered as Washington (D.C.) .W18, which files before Washington (State) .W2.
- The same letter-digit combination is used for different places in the two tables (e.g., Maryland .M3 and Manitoba .M3; New Jersey .N5 and New Brunswick .N5); pick from the table that matches the caption.
- Pennsylvania is printed ".P4" in the manual (a stray leading period in the source); the Cutter is P4.
