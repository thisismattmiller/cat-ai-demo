## Applies when

- A Cutter must be built for a word: the 1XX and/or 245 field (main entry or title), a subject or geographic term, a biographee, or any A-Z breakdown in a schedule, when the schedule gives no printed Cutter and nothing in the shelflist forces a different digit.
- The heading or title begins with an Arabic or Roman numeral (use the .A12-.A19 span, sec. 3).

## Rules

**Background.** The book number is the part of the call number that distinguishes a particular work from others in the same class. In the LC classification system, the book number is represented by the Cutter or part of the Cutter. In the shelflist and on the shelf, the Cutter is the means by which an alphabetical arrangement of books is achieved. This alphabetical arrangement is based on the LC filing rules (see G 100) and the Preferred Shelflist Order table (see G 65). The Library's book numbers are composed according to the table below (published in the Cataloging Service Bulletin in 1964, revised 1971, 1972, 1979; the third-letter table was introduced in 1979).

Cutters are treated as decimal numbers, which permits infinite expansion between any two Cutter numbers:

```
.B3
.B47
.B56
.B583
.B66
.B7
```

1. **Finding the filing position in the shelflist** [sec. 1]. Consult the class number in the shelflist. Find the proper location for the work being shelflisted, i.e. determine where the work is to file according to standard shelflisting practices. In many cases, this will be in alphabetical order by the 1XX and/or 245 fields.

2. **Cuttering for words** [sec. 2]. After determining the filing position of the work, consider whether use of the Cutter Table (below) to create the Cutter will achieve the proper position. If so, use the table. If not, complete the Cutter in order to fit in alphabetically with works already shelflisted.
   - The table gives the first digit after the initial letter, chosen by the second letter of the word (or the third letter after Qu). Further digits are added from the "For expansion" row, one digit per succeeding letter, as needed to file correctly and leave room.
   - Cutters without asterisks in the worked examples conform to the table. Cutters with a single asterisk have been developed when a range of letters in the table has been provided, e.g., l-m. Cutters with two asterisks have been developed when the second letter is not explicitly stated in the table, e.g., h after an initial consonant. In most cases, Cutters must be adjusted to file an entry correctly and to allow room for later entries.
   - **Note: Do not end a Cutter with the numeral 1 or 0.**
   - For ampersands and initials, see G 100, sec. 14 (as cited in the manual; the ampersand rule is G 100 sec. 16 and initials are G 100 sec. 11).

3. **Cuttering for numerals** [sec. 3]. When Cuttering for Roman or Arabic numerals, use the Cutters .A12-.A19. However, if entries already in the shelflist have been assigned "documents numbers" (e.g., .A5 for the corporate heading United States. Department of ...) Cutter numerals to file directly after those entries. Because of the infinite range of numbers, choose a Cutter toward the center of the available span when Cuttering for the first numeral in a class. This will allow room for both smaller and larger numbers. Follow this practice even with relatively low numbers since decimal fractions are filed in numeric order before the number 1.

## Examples

Example #1 [sec. 3] (Cuttering for the numeral "100" using the span .A12-.A19); the title beginning with a numeral files before titles beginning with A:

```
Title:  100 best hamburger recipes ... 2006.

        050 00 $a TX749.5.B43 $b A142 2006

Title:  A1 Steak House favorites ... 1998.

        050 00 $a TX749.5.B43 $b A213 1998

Title:  America's favorite beef recipes ... 1998

        050 00 $a TX749.5.B43 $b A45 1998
```

Example #2 [sec. 3] (Cuttering for multiple entries using the span .A12-.A19); identical numeric openings distinguished by successive expansion:

```
Title:  1981 commercial composite infrared index, grating molecular index ... 1982.

        050 00 $a QC457 $b .A15 1982

Title:  1981 commercial composite infrared index, grating numerical index ... 1982.

        050 00 $a QC457 $b .A154 1982

Title:  1981 commercial composite infrared index, grating spec-finding index ... 1982.

        050 00 $a QC457 $b .A156 1982
```

Example #3 [sec. 3] (Cuttering for a numeral where document numbers have been used); the numeral title is Cuttered to file directly after the .A5 documents number:

```
Main entry:  United States. Army. Ordnance Depot Platoon, 502nd
Title/Date:  Handbook of ordinance data ... 1918.

        050 00 $a UF523 $b .A5 1918a

Title entry:  1880's American arms ... 1981.

        050 00 $a UF523 $b .A53 1981
```

## Pitfalls

- Never end a Cutter with 1 or 0 [sec. 2, Note].
- The table is a starting point, not the answer: the Cutter must land in the correct alphabetical position among works already shelflisted and leave room for later entries; adjust when it would not [sec. 2].
- Letters not explicitly in the table (e.g. h after a consonant, ch- after S is 3 but Sc- is not listed) require an interpolated digit (Scanlon .S29, Chertok .C48, Clark .C58) [sec. 2 examples].
- After initial Qu the *third* letter is examined; Qa-Qt use 2-29 (Qadduri .Q23) [Table].
- Numerals: use .A12-.A19, choose toward the center of the span for the first numeral in a class, and remember that decimal fractions (e.g. .303) file before 1; if documents numbers (.A5 etc.) already occupy the head of the class, numerals go directly after them instead [sec. 3].
- For ampersands and initials, G 100 governs how the heading files, and therefore what letters the Cutter is built from [sec. 2].
