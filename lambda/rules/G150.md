  How to Cutter a translation or a text in parallel languages: take the Cutter of the
  original work and apply the Translation Table (.x13 English, .x14 French, .x12 polyglot,
  etc.), with the exceptions (corporate/conference creators, serials, autobiographies,
  Biography Table, "By date" captions, "By language, A-Z" captions).
---

## Applies when

- The record contains one or more 7XX fields (or a 240) with the preferred title of the work plus a language ($l) at the end, i.e. the resource is a translation or contains texts in parallel languages.
- Texts in parallel languages, any of three kinds: (1) the original language plus one or more translations; (2) two or more translations without the original; (3) "language editions" published simultaneously in multiple languages where the original language cannot be determined (e.g., documents of international bodies, tête-bêche resources without translation statements).
- Entry is under personal author or title. (Corporate and conference creators are excluded; see Pitfalls.)
- NOT covered: compilations of separate works in various languages (e.g., a collection of essays, one each in German, English, Spanish, and Russian); resources containing only small sections of translation (e.g., a French resource with a summary translated into English).

## Rules

1. [sec. 1] **General rule.** Use the Translation Table when assigning a Cutter number for a translation only when entry is under personal author or title and the preferred title plus the language is provided. Distinguish translations from the original work by using the Cutter number of the original work modified by the application of the Translation Table.
2. [sec. 1] **Do not use the Translation Table:**
   - for entries with a corporate or conference creator (cf. G 220, sec. 1.b);
   - for serials (see sec. 6);
   - for autobiographies or correspondence;
   - when using the Biography Table, except for the .xA6-Z area (cf. G 320);
   - when a caption includes the instructions "By date," unless a subarrangement is explicitly printed in the schedules.
3. [sec. 2] **Two or more languages.**
   - If the work contains the text in the original language and a single translation, use the Translation Table and Cutter for the language of the translation.
   - If the publication is a collection of two or more translations of a work, or the original language and two or more translations, use the Translation Table and add .x12 (Polyglot) to the Cutter.
4. [sec. 3] **Languages not listed.** If a language is not listed on the Translation Table, select a number for that language that would agree alphabetically with the table. Do not repurpose a number listed in the Translation Table. (E.g., Dutch files between Chinese .x127 and English .x13, so it can be shelflisted at .x129.)
   - Until 2013, if a language was not listed, a number was selected that would agree alphabetically with the table and any translation(s) previously shelflisted in the same class (e.g., if a German translation was already at .x15, a Hebrew translation could be .x16, Portuguese .x17, etc.). Continue this practice only when that pattern has already been established for a particular work.
5. [sec. 4] **Earlier practice.** If the number one (1) was omitted from the number representing the translation (e.g., .x for the original work, .x3 for an English translation, .x4 for French, .x5 for German, etc.), continue this practice only when the pattern has already been established for that work. Use the Translation Table without the numeral one.
6. [sec. 5] **By language, A-Z.** When the caption *By language, A-Z* appears in the classification schedules, do not apply the Translation Table. Instead, Cutter for the language itself, e.g. .E5 for English, .F7 for French, .G4 for German, etc.
7. [sec. 6] **Serials.** If a translation of a serial is classed in the same number as the serial in the original language, use successive Cutter numbers to arrange the translations in alphabetical order by language.
8. [sec. 7] **Two translations into the same language in the same year.** In order to avoid identical call numbers, add a work letter to the date of the second item shelflisted (cf. G 140 sec. 2).
9. The Translation Table has been applied only on the basis of a preferred title plus language since 1983. Before 1983 it was also applied when the statement of responsibility indicated a translation or the cataloger indicated a uniform title was not available; that practice was discontinued in 1983.

| .x14 | French translation |

"By language, A-Z" caption: Cutter for the language itself [sec. 5]. Example:

| Language | Cutter |

| Dungan | .D86 |
| Dusus | .D87 |
| Swahili | .S92 |

## Examples

English translation of a work entered under personal author, preferred title + language in 240; original Cutter .R68 + .x13 [sec. 1]:

```
050 00 $a JN6760 $b .R6813 [date]
100 1# $a Rousseau, Jean-Jacques, $d 1712-1778.
240 10 $a Considérations sur le gouvernement de Pologne. $l English
245 10 $a Considerations on the government of Poland /$c by Jean-Jacques
Rousseau ; translated from the French by Willmoore Kendall.
```

Original language plus a single translation (Greek original + English); add .x13 to the Cutter [sec. 2]:

```
050 00 $a D58 $b .H4713 [date]
100 0# $a Herodotus.
245 14 $a The histories.
700 02 $a Herodotus. $t Histories.
700 02 $a Herodotus. $t Histories. $l English.
```

[A collection of the original Greek expression and an English translation. Add .x13 from the Translation Table to the Cutter.]

Original English plus a Spanish translation; add .x18 to the second Cutter [sec. 2]:

```
050 00 $a QE862.O65 $b M25218 [date]
100 1# $a Mattern, Joanne, $d 1963-
245 10 $a Triceratops = $b Triceratops / $c by Joanne Mattern.
700 12 $a Mattern, Joanne, $d 1963- $t Triceratops.
700 12 $a Mattern, Joanne, $d 1963- $t Triceratops. $l Spanish.
```

[A collection of the original English expression and a Spanish translation. Add .x18 from the Translation Table to the second Cutter.]

Parallel Italian/English text; Italian title chosen as preferred title, English treated as the language of translation; add .x13 to the second Cutter [sec. 2]:

```
050 00 $a N6923.N49 $b M4713 [date]
100 1# $a Mereu, Angelino.
245 13 $a Il Nivola ritrovato : $b un artista tra l'America e il Mugello
      = Nivola rediscovered : an artist in America and the Mugello area
      / $c Angelino Mereu.
700 12 $a Mereu, Angelino. $t Nivola ritovato.
700 12 $a Mereu, Angelino. $t Nivola ritovato. $l English.
```

[Contains parallel text in Italian and English. The Italian title was chosen as the preferred title for the work. The English text is considered to be the language of translation. Add .x13 from the Translation Table to the second Cutter.]

Two translations (Catalan and Spanish) of an English original, original not present; polyglot .x12 on the second Cutter [sec. 2]:

```
050 00 $a NA7386.M3 $b B812 [date]
100 1# $a Byne, Arthur, $d 1883-1935.
245 10 $a Casas y jardines de Mallorca = $b Cases i jardins de Mallorca
/ $c Arthur Byne, Mildred Stapley.
700 12 $a Byne, Arthur, $d 1883-1935. $t Majorcan houses and gardens. $l
Catalan.
700 12 $a Byne, Arthur, $d 1883-1935. $t Majorcan houses and gardens. $l
Spanish.
```

[A collection of Catalan and Spanish translations of a work originally written in English. Add .x12 from the Translation Table to the second Cutter.]

Original Dutch plus English and French translations (three languages); polyglot .x12 [sec. 2]:

```
050 00 $a PT5882.12.E78 $b O3812 [date]
100 1# $a Bert, Kari.
245 10 $ Olaf Pirandello /  $c Kari Bert ; illustrations and translation
in French, Gilberte De Leger.
700 12 $a Bert, Kari. $t Oefeningencahier.
700 12 $a Bert, Kari. $t Oefeningencahier. $l English.
700 12 $a Bert, Kari. $t Oefeningencahier. $l French.
```

[A collection of the original Dutch expression with English and French translations. Three languages are present, so the resource is considered to be polyglot. Add .x12 from the Translation Table to the Cutter. Note: RDA core cataloging requires that an analytical entry be made for only two of the language forms.]

Title entry, parallel text in five languages; polyglot .x12 [sec. 2]:

```
050 00 $a HD9370.5 $b D5612 [date]
245 00 $a Diplôme international de l'OIV en management du secteur de la
      vigne et du vin ...
730 02 $a Diplôme international de l'OIV en management du secteur de la

730 02 $a Diplôme international de l'OIV en management du secteur de la
      vigne et du vin. $l English.
```

[Contains parallel text in French, English, German, Italian, and Spanish, and is considered to be a polyglot resource. Add .x12 from the Translation Table to the Cutter. Note: RDA core cataloging requires that an analytical entry be made for only two of the language forms.]

Language not in the table (Dutch); number chosen to file alphabetically between Chinese .x127 and English .x13 [sec. 3]:

```
050 00 $a E58 $b .L16129 [date]
100 1# $a Lafitau, Joseph-François, $d 1681-1746.
240 10 $a Mœurs des sauvages ameriquains. $l Dutch
245 13 $a De zeden der wilden van Amerika / $c door den zeer geleerden
J.F. Lafiteau.
```

[The Translation Table provides .x127 for Chinese and .x13 for English. This Dutch translation should file between them, and can be shelflisted at .x129.]

## Pitfalls

- Do not apply the Translation Table to entries with a corporate or conference creator; those receive the same Cutter as all other publications under the same heading (G 220 sec. 1.b; G 230 sec. 1.d).
- Do not apply it to serials (use successive Cutters arranged alphabetically by language, sec. 6), to autobiographies or correspondence, or within the Biography Table except in the .xA6-Z area (G 320).
- Do not apply it when the caption says "By date," unless a subarrangement is explicitly printed in the schedules.
- When the caption is "By language, A-Z," Cutter for the language name itself, not with the table (sec. 5).
- When the original language is present with exactly one translation, Cutter for the language of the translation, not for the original (sec. 2). With two or more translations (with or without the original), use .x12 polyglot. Since 2013 polyglot means 2 or more languages of translation; before 2013 it meant 3 or more.
- Never repurpose a number already listed in the table for an unlisted language (sec. 3). The older "next free number" practice for unlisted languages and the older "no numeral 1" pattern (.x3 English, .x4 French, ...) continue only where already established for that work (secs. 3–4).
- When the preferred title of a parallel text is in one of the languages, that language is the original and the other language is the language of translation (Mereu example).
- The table is applied to the Cutter for the work: where the Cutter for the work is the second Cutter (class number already carries a subject/topical Cutter), the table digits go on the second Cutter (Mattern, Mereu, Byne examples).
