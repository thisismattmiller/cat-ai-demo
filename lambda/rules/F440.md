## Applies when
- The 050 $a in the record ends with a plus sign ("+"), meaning only the classification portion has been assigned and the unique book number still has to be built.
- The 050 contains a second $a subfield (an alternate or bracketed alternative number).
- The 050 carries parenthetical hints such as "(Mexico)", "(Thatcher)", "(Danish)", "(P-PZ40)" or a Cutter span such as "A5-59".

## Rules
1. How the information is given. The class number is input in the 050 field, ending with a +. Alternate numbers are input as a second $a subfield. [sec. 1]
2. What the 050 with "+" can contain [sec. 2]:
   - a. Class numbers: the assigned class number, input as in sec. 1. [sec. 2.a]
   - b. Collected sets: both the collected set number in an 050 $a subfield and the bracketed alternative monograph number in a second $a subfield. [sec. 2.b]
   - c. Bibliography and incunabula: both the assigned class number in an 050 $a subfield and an alternative number in a second $a subfield. [sec. 2.c]
   - d. Topical information for unprinted Cutters: enough information to formulate a complete call number. Under "By region or country, A-Z" the country for which the Cutter is to be supplied is indicated; under "Individual biography, A-Z" the person for whom the Cutter is to be supplied is indicated. [sec. 2.d]
   - e. Tables: complete information from tables accompanying the schedules, including topical Cutters, the appropriate Cutter number or span or subarrangement taken from the table, and the table number being used, as appropriate. [sec. 2.e]
   - f. Literary authors: the following information is given [sec. 2.f]:
     - The complete class number (including Cutter number, if applicable) for the author, if a number has already been established. If the author is not yet established, the number and the first letter of the Cutter number. If the schedule provides more than a single number for the author, the specific number or Cutter appropriate for the work.
     - The Cutter or Cutter span, taken from the appropriate table, that applies to the specific work.
     - Any additional information required by Cutter spans, such as editor, translator, language, title, etc.
     - The number of the table that is being used.
   - h. Main entry Cuttering not needed. No additional Cuttering information is given for the main entry, since Cuttering for main entry is a normal shelflisting procedure requiring no special instruction. [sec. 2.h]
3. Reading the notation: ".x" followed by a Cutter (e.g., ".xA3", ".x2P+", ".xZ5-999") means the table Cutter is appended to the Cutter that is to be supplied for the place, person, etc. named in the preceding parenthesis. A span (e.g., "A3-39", ".A6-Z", "A61-Z458") is the range from the named table within which the work's Cutter must fall. [secs. 1, 2.e, 2.f]

## Examples
Class numbers ending with + and alternate numbers as second $a [sec. 1]:
```
050 00 $a QE535.5.U+  (United States)
050 00 $a HV9515.T (Tampico) .x2P+ (Penal de Andonegui)
050 00 $a LD5351.T55A8-T55Z+
050 00 $a PS3517.R87A5-A59+ (Danish)
050 00 $a Z5815.B5+ $a LA 551
```

Collected set number with bracketed alternative monograph number as second $a [sec. 2.b]:
```
050 00 $a QH301+ $a QL513.T3
```

Topical information for an unprinted Cutter — By region or country, A-Z [sec. 2.d]:
```
050 00 $a GV944.M+ (Mexico)
```
[indicate country for which Cutter is to be supplied]

Topical information for an unprinted Cutter — Individual biography, A-Z [sec. 2.d]:
```
050 00 $a DA591.T+ (Thatcher)
```
[indicate person for whom Cutter is to be supplied]

Tables — subarrangement for autobiography [sec. 2.e]:
```
050 00 $a Q143.P2 A3+
```
(A3 = subarrangement for autobiography)

Tables — Cutter span from Table II [sec. 2.e]:
```
050 00 $a E757.A6-Z+
```
(.A6-Z = Cutter span from Table II)

Tables — biographee plus biography-table Cutter [sec. 2.e]:
```
050 00 $a V63.L (Love) .xA3+
```
(.L (Love) = Name of biographee)
(.xA3 = Cutter from the general (for an autobiography) biography table]

Tables — biographee plus span from Table P-PZ40 [sec. 2.e]:
```
050 00 $a PL3748.S (San) .xZ5-999+ (P-PZ40)
```
(.S (San) = Name of biographee)
(.xZ5-999 (P-PZ40) = Cutter span from Table P-PZ40)

Literary author not yet established, translation span with translator named [sec. 2.f]:
```
050 00 $a PS3513.R  A3-39+ (Smith) (P-PZ40)
```
[PS3513 = Class number]
[.R = Cutter (author not yet established)]
[A3-39 = Cutter span (translations into French)]
[Smith = Translator]
[P-PZ40 = Table number]

Literary author already established, separate works span with title named [sec. 2.f]:
```
050 00 $a PL3748.G8 A61-Z458+ (Chu) (P-PZ40)
```
[PL3748 = Class number]
[.G8 = Cutter (author already established)]
[A61-Z458 = Cutter span (separate works)]
[Chu = Title to be Cuttered for]
[P-PZ40 = Table number]

Literary author already established, other-languages span with language named [sec. 2.f]:
```
050 00 $a PS3517.R87 A5-59+ (Danish) (P-PZ40)
```
[PS3517 = Class number]
[.R87 = Cutter (author already established)]
[A5-59 = Cutter span (other languages)]
[Danish = Language to be Cuttered for]
[P-PZ40 = Table number]

## Pitfalls
- A "+" at the end of 050 $a is not part of the call number; it marks the number as incomplete. The parenthetical words after it are hints, not call-number elements. [sec. 1]
- When a literary author's schedule number provides more than one number for the author, the specific number or Cutter given is the one appropriate for the work in hand, not the author's general number. [sec. 2.f]
- If the schedule does not yet indicate which table applies for a specific author or area, a proposal to add the table number is required; do not guess a table. [sec. 2.f]
- The main entry Cutter is never spelled out in this information; supply it by normal shelflisting procedure. [sec. 2.h]
