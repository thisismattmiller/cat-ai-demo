  How to build call numbers for scores and other music materials in M/ML/MT: single vs.
  double Cutter, additions after the composer Cutter (opus number, thematic index number,
  serial number, key, date of composition), Cuttering of collections, arrangements, vocal
  music, masses, excerpts and selections, the Music Translation Table, and the list of
  un-Cuttered and semi-Cuttered M/MT classes.

## Applies when

- The resource is music (a score, part, or other music material) classed in subclasses M, ML, or MT.
- Books *about* music are shelflisted following the provisions for shelflisting other materials; this chapter's special Cuttering does not apply to them.
- The class number appears in the Appendix list of un-Cuttered, semi-Cuttered, or "sep" classes.

## Rules

### 1. General procedures

**a. Instrumental music.**

1. [sec. 1.a(1)] **Works entered under title.** Single Cutter works entered under title.
2. [sec. 1.a(2)] **Opus number or thematic index number.** Add the opus number or thematic index number whenever it appears in the uniform title (e.g., `.P515 op. 151 1983`; `.K34 op. 3, no. 19 1980`; `.S28 K. 159 1991`).
3. [sec. 1.a(3)] **Other additions.** If the opus number or thematic index number is not given, and the class number is not specifically for the individual title or uniform title of the work, add one of the following elements, in the following order of preference:
   1. serial number (e.g., `no. 2`)
   2. key (major is abbreviated as `maj.`; minor is abbreviated as `min.`; e.g., `G min.`)
   3. date of composition (enclosed in parentheses, e.g., `(1982)`)
   4. Double Cutter by title or editor, etc. (e.g., `.O744B5`)

   If none of these elements is available, single Cutter. The publication date follows the addition (e.g., `.O8 (1982) 1983`).

**b. Collections.**

4. [sec. 1.b(1)] **Collected works.** Single Cutter collected works by one composer classed in M3.
5. [sec. 1.b(2)] **Collection of works by one composer.** Double Cutter collections of works by one composer that have a uniform title that means the same as the class number (i.e., works, songs, quartets, piano works, etc.). Assign the first Cutter for the name of the composer. Assign a second Cutter for the compiler, editor, arranger, or publisher. If none of the above appears, or the publisher is a very common one, assign a second Cutter for the title.

**c. Arrangements.**

6. [sec. 1.c(1)] Assign a first Cutter for the composer. Assign a second Cutter for the title with a digit representing the arranger.
7. [sec. 1.c(2)] If the composer is the arranger, do not assign a second Cutter.
8. [sec. 1.c(3)] If the name of the arranger is not given, base the second Cutter on the editor or publisher.

**d. Vocal music.**

9. [sec. 1.d(1)] **General principle.** Double Cutter for composer and title.
10. [sec. 1.d(2)] **Pattern existing in the shelflist.** If a pattern using thematic index numbers as part of the call number has already been established in the shelflist, follow the existing pattern.
11. [sec. 1.d(3)] **Masses.** Double Cutter by the name of the composer and the person whom the Mass honors. Ignore words like Saint, Pope, Blessed, etc. If the Mass is not written in honor of an individual, base the second Cutter on the first significant word in the title, ignoring words like *Mass* and *Missa*. If a pattern has already been established using the opus number, key, or number of the Mass, follow the existing pattern. If none of these options are possible, the words *Mass* or *Missa* may be used.

**e. Excerpts.**

12. [sec. 1.e] Add a digit for the excerpt to the Cutter number for the title. If an excerpt has been expressed by a number, add the number to the Cutter number for the title. If the work is an excerpt of an excerpt, use an additional digit (e.g., `P7` Preludes, `P71` book 1, `P716` Minstrels, `P7168` arranger).

**f. Selections.**

13. [sec. 1.f] Double Cutter selections from a composer's work for the type of music named in the uniform title with another digit for the editor, arranger, publisher, or title. If the uniform title is *Selections*, base the second Cutter number on the editor, arranger, publisher, or title.

**g.–h. Accession numbers.**

14. [sec. 1.g] **ML94-ML96 materials.** Add the accession number below the Cutter number for the composer in classes for holographs (ML94-ML96) whenever introducing a new composer in these classes.
15. [sec. 1.h] **ML29-ML31 materials.** Add the accession number below the Cutter number for the composer in the special foundations classes (ML29-ML31) whenever another system has not been firmly established (e.g., `ML31 .M24e no. 1095`; `ML30.4c no. 2765 Miller`).

**i. Translations.**

16. [sec. 1.i] For translations, use the Music Translation Table (below). If the item is not a translation, if possible, use a single digit for the title portion of the call number.

### 2. Special assignments

17. [sec. 2.a] **Case assignments.** Assign to the Case rare materials such as rental materials, librettos, holographs, publications of special foundations, and items published before 1800.
18. [sec. 2.b] **Folio.** Assign music 40 cm. in height and over to folio.

### 3. Content designation of call numbers

19. [sec. 3] Apply the standard conventions for inputting call numbers. See the examples (opus/thematic numbers, keys, dates of composition, volume designations such as `vol. 12` or `Heft 1`, and accession numbers appear in $b after the Cutter; an alternate class number appears in a second $a).

### Appendix: un-Cuttered, semi-Cuttered and "sep" classes

20. In the music shelflist, some numbers in the M and MT subclasses are considered semi-Cuttered, while others are considered un-Cuttered. **Semi-Cuttered** means that the first Cutter number is usually for an instrument or other aspect of the work and that the call number is not completed beyond the second Cutter letter. **Un-Cuttered** means that the call number is not completed beyond the first Cutter letter. In the list of M class numbers below, the designation *semi* indicates that the call number is completed only through the second Cutter letter; the designation *sep* indicates classes in which collections are Cuttered and separate works are un-Cuttered. (Numbers listed without a designation are un-Cuttered.) E.g., `M175.X6 $b H` (un-Cuttered beyond the first letter of the second Cutter); `M175.H8 $b Y5` (M175 semi, sep).
21. In subclass MT, all decimal numbers are treated as un-Cuttered classes except those listed below; the additional whole numbers listed below are also treated as un-Cuttered.

## Examples

Title entry, instrumental music: single Cutter by title [sec. 1.a(1)]:

```
Title/Date:  Novo mesto ... c1991.

050 00 $a M23 $b .N937 1991
```

Opus number from the uniform title added after the composer Cutter [sec. 1.a(2)] (indicators printed in the manual as `0500`):

```
Main entry:  Persichetti, Vincent, 1915-1987.
Uniform title:  [Sonatas, harpsichord, no. 4, op. 151]
Title/date: Fourth harpsichord sonata ... c1983.

0500 $a M23 $b .P515 op. 151 1983
```

Opus number and second number [sec. 1.a(2)]:

```
Main entry:  Kempis, Nicolaus a, approximately 1600-1676.
Uniform title:  Symphonies, op. 3. No. 19
Title/date:  Symphonia no. 2, opus 3 ... c1980

050 00 $a M422 $b .K34 op. 3, no. 19 1980
```

Thematic catalog number [sec. 1.a(2)]:

```
Main entry:  Scarlatti, Domenico, 1685-1757.
Uniform title:  Sonatas, harpsichord, K. 159, C major
Title/date:  Sonata in C major (K. 159) ... c1991.

050 00 $a M23 $b .S28 K. 159 1991
```

Serial number (no opus/thematic number) [sec. 1.a(3) 1)]:

```
Main entry:  Samarco, John Philip.
Uniform title:  Sonatas, piano, no. 2
Title/date:  Second sonata for piano ... c1991.

050 00 $a M23 $b .S145 no. 2 1991
```

Key [sec. 1.a(3) 2)]:

```
Main entry:  Schumann, Clara, 1819-1896.
Uniform title:  Sonata, piano, G minor
Title/date:  Sonate für Klavier, g-Moll ... c1991.

050 00 $a M23 $b .S518 G min. 1991
```

Date of composition in parentheses, followed by publication date [sec. 1.a(3) 3)]:

```
Main entry: Otey, Orlando.
Uniform title:  Sonatas, piano (1982)
Title/date:  Sonata for piano, 1982 ... c1983.

050 00 $a M23 $b .O8 (1982) 1983

Main entry:  Ligeti, György, 1923-2006.
Uniform title:  Concertos, violin, orchestra (1990)
Title/date:  Konzert für Violine und Orchester (1990) ...  c1990.

050 00 $a M1012 $b .L64 (1990) 1990

Main entry:  Ligeti, György, 1923-2006.
Uniform title:  Concertos, violin, orchestra (1992)
Title/date:  Konzert für Violine und Orchester (1992) ... 2.
             c1992.

050 00 $a M1012 $b .L64 (1992) 1992
```

Double Cutter by title (no uniform title with number, key or date) [sec. 1.a(3) 4)]:

```
Main entry:  Ornstein, Leo, 1892-2002.
Title/date:  Biography in the form of a sonata ... c1977-

050 00 $a M23 $b .O744B5 1977

Main entry:  Ohana, Maurice, 1913-1992.
Title/date:  Sonatine monodique.  1967

050 00 $a M23 $b .O37S6 1967
```

Single Cutter, none of the elements available [sec. 1.a(3)]:

```
Main entry:  Paynter, John
Uniform title:  Sonata, piano
Title/date:  Sonata for piano ... c1987.

050 00 $a M23 $b .P396 1987
```

Excerpt expressed by a number: number digit added to the title Cutter [sec. 1.e]:

```
Main entry:  Leclair, Jean Marie, 1697-1764.
Uniform title:  Récréation de musique d'une exécution facile, no. 2
Title/date:  Deuxième récréation de musique d'une exécution ... 1993?

050 00 $a M317.L43 $b R42 1993

R4 = Récréation
R42 = Récréation + no. 2
```

```
Main entry:  Mestral, Patrice, 1945-
Uniform title:  Bloc, no. 2
Title/date:  Bloc II ... c1982

050 00 $a M322.M57 $b B62 1982

B6 = Bloc
B62 = Bloc + no. 2
```

Excerpt of an excerpt, arranged: digits for book, excerpt, and arranger [sec. 1.e; sec. 1.c]:

```
Main entry:  Debussy, Claude, 1862-1918.
Uniform title:  Preludes, piano, book 1. Minstrels; arranged
Title/date:  Minstrels / Claude Debussy ; arranged by Raymond
Vunkannon ... c1989.

050 00 $a M1060.D28 $b P7168 1989

P7 = Preludes
P71 = Book 1
P716 = Minstrels
P7168 = Vunkannon, Raymond (arranger)
```

Selections: second Cutter for the type of music named in the uniform title plus a digit for the editor [sec. 1.f]:

```
Main entry:  Lambert, Michel, 1610-1696.
Uniform title:  Pièces en trio. Selections
Title/date:  Pièces en trio : 24 Stücke ... / Michel Lambert ;
    [herausgegeben von] Siegbert Rampe ... c1989-c1990.

050 00 $a M317.L19 $b P57 1989

P5 = Pièces en trio
P57 = Rampe, Siegbert (editor)
```

```
050 00 $a M2 $b .E12 vol. 20, etc. $a M3.1

050 00 $a M1012.5 $b .B3 op. 61 .S5 1984
```

## Pitfalls

- Several Cuttering methods coexist in the same class and even for the same composer (opus numbers, serial numbers, keys); where an older pattern exists in the shelflist, new entries are made to fit the old system rather than the current rule [Background; sec. 1.d(2); sec. 1.d(3)].
- The order of preference in sec. 1.a(3) applies only when no opus/thematic index number is in the uniform title *and* the class number is not specifically for the individual title/uniform title of the work; if it is, do not add these elements.
- Key abbreviations are exactly `maj.` and `min.`; date of composition is enclosed in parentheses and precedes the publication date (`(1982) 1983`).
- Arrangements: no second Cutter when the composer is also the arranger [sec. 1.c(2)].
- Masses: ignore Saint, Pope, Blessed, etc. in the honoree's name; ignore Mass/Missa when Cuttering from the title [sec. 1.d(3)].
- Translations of music materials use the Music Translation Table (.x2 English, .x3 French, .x4 German, .x5 Italian/Latin ...), which differs from the general Translation Table in G 150 (.x13 English, etc.) [sec. 1.i].
- Many M and MT classes are un-Cuttered or semi-Cuttered: do not complete the call number beyond the first (un-Cuttered) or second (semi-Cuttered) Cutter letter in those classes; in *sep* classes only collections are Cuttered and separate works are un-Cuttered [Appendix].
- In MT, decimal numbers are un-Cuttered unless listed among the eleven exceptions [Appendix].
- Rare music (rental materials, librettos, holographs, special-foundation publications, pre-1800 imprints) is assigned to the Case; music 40 cm. or taller is assigned to folio [sec. 2].
- Books about music are shelflisted by the ordinary (non-music) provisions [Background].
