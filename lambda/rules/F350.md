## Applies when

- The class number ends in an alphabetical list of topics expressed as Cutter numbers
  ("Special, A-Z", "By region or country, A-Z", "Regions, counties, etc., A-Z", etc.), and
  the topic, place, name, language or title of the work must be matched to an existing or new
  Cutter.
- The printed list is preceded by "e.g." (a representative sample rather than a complete
  list).

## Rules

1. Topical Cutters in an alphabetical list are printed in the LC classification schedules and
   are established in the same manner as class numbers; the editorial staff will adjust the
   numeric portion of the Cutter number if necessary. If a topical Cutter number has previously
   been used but not incorporated into the schedules, establish it as a new number when
   assigning it to new material or when otherwise convenient. Formerly, in certain areas of
   the classification, only a representative sample of topical Cutters was printed under a
   number, preceded by the notation e.g.; that practice is no longer followed for topical
   Cutters. If such an arrangement is encountered and a new topic is being established, the
   e.g. notation is cancelled and the new topic established (and, time permitting, other
   topics existing in the shelflist). [sec. 1]
2. Unprinted Cutter numbers. The following types of Cutter numbers are generally not printed
   in the LC classification schedules and need not be established: personal, corporate, and
   geographic names, names of languages (when a topic is subarranged by language), and titles
   of individual works, except for literary works from early periods up to 1500. In some areas
   a few representative Cutter numbers of these types are printed, preceded by the notation
   e.g.; these representative listings are not cancelled, but no additional examples are added
   to them. [sec. 2]
3. Formulating the caption for new topical Cutter numbers. When possible, formulate the
   caption to match the subject heading unless the nature and context of the list dictates
   that a caption other than the established subject heading should be used. Follow existing
   patterns in each topical Cutter number list. When double captions are used or Including
   notes are proposed under a caption, make a see reference from the alphabetical position of
   the alternate terminology. Formulate the see reference using the full classification
   number, i.e., the class letters, class number, and Cutter number, even for numbers within
   the same Cutter number list. [sec. 3]
4. Hierarchy in Cutter number developments. Do not build hierarchy into topical Cutter number
   developments unless this practice is already well established, as in QL737. [sec. 4]

## Examples

Alphabetical list of topics as Cutter numbers [Background]:
```
          Vegetables, cereals, fruits, etc.
TX557       General works
TX558       Special, A-Z
TX558.A3      Acorns
TX558.A6      Apples
TX558.B3      Bananas
```

Double caption with see references from the alternate terms, each giving the full class
number [sec. 3] (lines marked in the manual with a marginal symbol are the see references
and the double caption they point to):
```
TX770.A-Z   Special breads, A-Z
TX770.C72     Crackers
              Crepes, see TX770.P34
TX770.M83     Muffins
TX770.P34     Pancakes. Waffles. Crepes
TX770.T65     Tortillas
              Waffles, see TX770.P34
```

Including note with a see reference from the included term [sec. 3]:
```
F247.A-Z    Regions, counties, etc., A-Z
F247.C3       Calhoun Co.
              Canaan Valley, see F247.T8
F247.H2       Hampshire Co.
F247.M5       Mercer Co.
F247.T8       Tucker Co.
                Including Canaan Valley
```

## Pitfalls

- A topic listed only as an "e.g." sample in an old-style list is still the number to use;
  the list is not exhaustive [sec. 1].
- Names of persons, corporate bodies, places, languages, and titles (except pre-1500 literary
  works) are Cuttered by the cataloger without a printed schedule entry [sec. 2].
- A term that appears only in a double caption or Including note (e.g. Crepes, Canaan Valley)
  takes the Cutter of the caption that includes it, not its own Cutter [sec. 3 examples].
- No sub-Cuttering hierarchy under a topical Cutter unless the list already does so (QL737)
  [sec. 4].
