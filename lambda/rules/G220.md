  How to Cutter works entered under a corporate body (and works about one): one Cutter per
  corporate heading (ignoring subordinate units; jurisdiction + first subordinate body for
  government bodies), date to distinguish, work letters b, c... for same-year publications,
  successive work letters a, b... for serials, same Cutter for translations/editions, and the
  handling of name changes, qualifiers, official-document classes and schedule tables.
  Not applied in class K.
---

## Applies when

- The 1XX field is a corporate body heading (110): association, government agency, religious body, local church, etc. (For conference headings (111) see G 230; for societies see G 240.)
- The work is *about* a corporate body, in a class where works about a corporate body are Cuttered with works by it [sec. 12].
- The class number is for the official documents of a specific country [sec. 15], or the schedule has special provisions or a table for corporate headings [sec. 16].
- The class number is NOT in Class K: the provisions of this chapter are not applied to items classed in K; there each corporate name is given a separate Cutter number.

## Rules

1. [sec. 1.a] **Corporate body in the 1XX, general rule.** For materials entered under a corporate body heading, Cutter for the name of the corporate body. Add the publication date to the call number to make each call number unique. For serials, see sec. 9.
2. [sec. 1.b] **Translations, selections, etc.** Assign the same Cutter number to all publications with the same corporate body heading, including translations, selections, editions, etc. (Do not apply the Translation Table.)
3. [sec. 2.a] **More than one publication in a given year: work letters.** If a corporate body issues more than one publication in a given year, add a work letter to the date of publication starting with `b` and continuing through the alphabet in the order of receipt.
4. [sec. 2.b] **Exact date of publication not known.** When the exact date of publication is not known and is provided in the format `[between (date) and (date)]`, use the earlier date. Do not add the letter `z` to the date when the exact date of publication is not known.
5. [sec. 3] **Subheadings in non-jurisdictional corporate names.** Ignore all bodies entered subordinately in establishing the Cutter number: the same Cutter number is used for the parent body even though the entries are for different units of it.
6. [sec. 4.a] **Subheadings in jurisdictional corporate names.** If the name of a corporate body consists of the name of a country or other jurisdiction (e.g., states, provinces, etc.) followed by a subfield for a division or agency of that government, base the Cutter number on two elements: the jurisdiction and the first subordinate body. Ignore all further subdivisions.
   - Note: Do not use the document .A Cutter number that was used before 1975 for a country or a geopolitical area, unless provisions are made for it in the schedules.
7. [sec. 4.b] **Jurisdictional names as part of corporate body headings.** If a jurisdictional name appears as the first word of a corporate name established as a phrase (e.g., `Vancouver School Board`), treat it as a non-jurisdictional name according to the provisions of sec. 3.
8. [sec. 5.a] **Corporate bodies with a Cutter number already established under earlier procedures.** When a Cutter number has been established for a corporate body under earlier procedures, a date was not added to the call number, and a new resource by the same corporate body is received, assign the next successive Cutter number to the new resource (and add the date; serials get the work letter on that successive Cutter).
9. [sec. 5.b] **Corporate bodies previously established in abbreviated form.** When a Cutter number has been established for a corporate body based on a heading that included an abbreviation (e.g., `Dept.`), and the RDA form of heading does not use an abbreviation, continue to use the existing Cutter number.
10. [sec. 6] **Two or more bodies with the same name, but with different qualifiers.** Use different Cutter numbers for two or more different bodies with the same name, but with different qualifiers. They are not the same corporate body.
11. [sec. 7] **Significant changes in the heading.** When there is a significant change in the heading for a corporate body because the body's name has changed, Cutter for the new heading.
12. [sec. 8] **Insignificant changes in the heading.** When insignificant or minor changes occur in the heading (e.g., AACR 1 `Maryland. State Board for Community Colleges` vs. AACR 2/RDA `Maryland State Board for Community Colleges`), use the same Cutter number.
13. [sec. 9] **Serials.** Formulate a unique call number for serials (periodicals and monographic series) cataloged under a corporate body heading by adding successive work letters, beginning with `a`, to the Cutter number for the corporate heading in order of receipt of the serial. (No date.)
14. [sec. 10] **Collected sets and other major arrangements.** Do not change the Cutter numbers of existing collected sets or other major arrangements that appear in the shelflist and are at variance with these guidelines. Instead, arrange the entries in the shelflist in alphabetical order by the 1XX and/or 245 fields.
15. [sec. 11] **Comparisons between monographs and serials.** When a corporate body publishes both monographic and serial works, use the same Cutter number for both, following the appropriate guidelines for monographs (date) and serials (work letter).
16. [sec. 12] **Works about corporate bodies.** In a class where there are works about a corporate body, use the same Cutter number for works about the corporate body as is used for works by the corporate body. Double Cutter by main entry (the corporate body's Cutter becomes part of $a; the second Cutter is for the main entry of the work about it).
17. [sec. 13] **Commentaries.** See G 340.
18. [sec. 14] **Supplements and indexes.** See G 155.
19. [sec. 15] **Official documents.** When the entire classification number is for the official documents of a specific country, disregard the name of the country or state appearing at the beginning of the entry. Base the Cutter number on the name of the division and ignore further subheadings. (Serial documents then take successive work letters on that Cutter.)
20. [sec. 16] **Special schedule provisions.** When the schedules have special provisions regarding corporate headings (e.g., a table such as L7a), follow the provisions of the schedule rather than the provisions of this instruction sheet.

## Pitfalls

- Class K is excluded: in K each corporate name gets its own separate Cutter (this chapter's "same Cutter for the parent body" rules do not apply there).
- Work letters for same-year monographs start at `b` (the first item has no letter); serial work letters start at `a` and replace the date. Do not use `z` for an unknown date [sec. 2].
- For `[between X and Y]` dates use the earlier date [sec. 2.b].
- Subordinate units of a non-jurisdictional body never get their own Cutter [sec. 3]; for jurisdictions the Cutter reflects jurisdiction + first subordinate body only, so `New York (State). Legislature. Assembly. Task Force ...` Cutters as New York (State) + Legislature [sec. 4.a].
- The pre-1975 document `.A` Cutter for a country/geopolitical area is not used unless the schedule provides for it [sec. 4.a note].
- A phrase heading beginning with a place name (`Vancouver School Board`) is non-jurisdictional [sec. 4.b].
- Bodies already Cuttered without a date under earlier procedures: new items get the *next successive Cutter* plus date, not the old Cutter plus date [sec. 5.a].
- Abbreviation vs. spelled-out form of the same heading is not a name change: keep the Cutter [sec. 5.b]. Minor heading changes keep the Cutter [sec. 8]; real name changes get a new Cutter [sec. 7]. Same name with different qualifiers = different bodies = different Cutters [sec. 6].
- Existing collected sets / major arrangements at variance with these rules are left as is [sec. 10].
- Where the whole class number is for a country's official documents, the country/state at the head of the entry is dropped from Cuttering [sec. 15].
- Schedule provisions (tables for corporate headings) always override this chapter [sec. 16].
