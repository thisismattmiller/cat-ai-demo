## Applies when
- The class number (or a table applied to it) carries the form caption "By region or country, A-Z" (or an equivalent such as "By country, A-Z"), so a geographic Cutter for a region or country must be supplied.
- A Cutter for a region or country is being assigned in a given class for the first time, or must be reconciled with Cutters already established there.
- The place is a dependency, region, historical jurisdiction or island not present in the table, and a Cutter must be created.

## Rules
1. Existing Cutters. If a Cutter for a region or country has been used in the shelflist or established in the classification schedule, use that number even if it is in conflict with the number in the regions and countries table. [sec. 1]
2. New Cutters. If a Cutter for a specific region or country is being applied for the first time in a particular class, and there is no conflict with adjacent Cutter numbers, use the Cutter indicated in the regions and countries table. If a conflict exists with adjacent Cutter numbers, continue the existing Cutter arrangement, adjusting the new Cutter to maintain the proper alphabetical arrangement. [sec. 2]
3. Special rules. For special rules related to creating Cutter numbers under captions reading By region or country, A-Z (or its equivalent), see F 430. [sec. 3]
4. Using new Cutters not listed in the table. If necessary to create a Cutter for a dependency, region, historical jurisdiction, or island not listed in the table, shelflist the item according to normal rules. Entities of this type are not normally added to the table. [sec. 4]
5. Scope of the table. The table contains all 195 independent countries as of 2019, 26 major dependencies and areas of special sovereignty, some historical jurisdictions or entities, and some islands. It is normally amended only when world events require the change of names of countries. [Background]
6. "see" entries in the table are cross-references: Cutter under the target name (e.g., England, Scotland, Wales, Northern Ireland are all Cuttered as Great Britain .G7; Hong Kong, Macao, Tibet, Inner Mongolia, Xianggang as China .C6).

## Examples
The chapter contains no worked call-number examples; the table itself is the example set.

## Pitfalls
- The table never overrides the shelflist: an existing Cutter for the same place in the same class wins even when it conflicts with the table. [sec. 1]
- When the table's Cutter would collide with or misfile against adjacent Cutters already in the class, do not force it in; adjust the new Cutter so that alphabetical order is kept. [sec. 2]
- Several present-day states appear only as "see" references to a name the table prefers (Myanmar see Burma; Swaziland see Eswatini; Cape Verde see Cabo Verde; Macedonia (Republic) see North Macedonia; Russia (Federation) see Russia; Korea (Republic)/(South) see Korea; Korea (Democratic People's Republic) see Korea (North)).
- Constituent parts of a country are not given their own Cutter: England, Scotland, Wales, Northern Ireland see Great Britain; Tasmania and Western Australia see Australia; Tamil Nadu see India; Siberia see Russia; Hong Kong, Macao, Tibet, Inner Mongolia see China; Jutland see Denmark (see F 430 for the principle).
- Distinct pairs with different Cutters: Armenia .A75 vs. Armenia (Republic) .A76; Micronesia .M625 vs. Micronesia (Federated States) .M626; Sudan .S73 vs. Sudan (Region) .S74; Samoa .S23 vs. Samoan Islands .S24; Virgin Islands .V6 vs. Virgin Islands of the United States .V63; Macedonia .M27 vs. North Macedonia .N74; Congo (Brazzaville) .C74 vs. Congo (Democratic Republic) .C75; Korea .K6 vs. Korea (North) .K7; Guiana .G915 vs. Guyana .G95 vs. French Guiana .F9.
- Historical entities keep their own Cutters (Byzantine Empire .B97, Czechoslovakia .C95, Islamic Empire .I742, Roman Empire .R57, Soviet Union .S65, Yugoslavia .Y8, Prussia, East (Poland and Russia) .P85) but Prussia itself is see Germany.
