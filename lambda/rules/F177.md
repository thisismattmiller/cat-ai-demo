## Applies when

- The work is a translation: a rendering from one language into another, or from an older
  form of a language into a modern form, more or less closely following the original.
- The schedule for the topic subdivides by language, by publication date, or is a
  dictionary/encyclopedia number broken down by language.
- The work is a translation of juvenile belles lettres (PZ5-90).

## Rules

1. General rule. Except as noted below, class a translation in the same number as the original
   work. Apply this rule even if the schedule provides for breaking down texts by language.
   For example, a German-language work about ancient philosophy is classed in B113. An English
   translation is classed with the original work in B113, not with English-language works about
   ancient philosophy in B111. [sec. 1]
2. Classification according to date of publication. See F 320 sec. 2.b.(3): assign the class
   number that corresponds to the publication date of the translation being cataloged even if
   this results in the work being separated from the original work. [sec. 2]
3. Obsolete classification numbers. If the classification number of the work in the original
   language is no longer a valid number, classify a translation in the currently authorized
   number. For general information on obsolete numbers, see F 185. [sec. 3]
4. Dictionaries and encyclopedias. If a specific classification schedule provides a breakdown
   for dictionaries and encyclopedias by language, class a translation with the language of
   the text rather than with the language of the original edition. [sec. 4]
5. Juvenile belles lettres. Class translations of juvenile belles lettres in PZ5-90 with the
   language of the translation, rather than with the language of the original text. [sec. 5]
6. Editions published simultaneously in different languages. See F 175 sec. 3 (first edition
   received is the "original"; the others are translations). [sec. 6]

## Examples

Translation stays with the original's language-based number:
German-language work about ancient philosophy classed in `B113`; its English translation is
classed in `B113`, not in `B111` (English-language works about ancient philosophy).

## Pitfalls

- Language breakdowns for texts do NOT move a translation; language breakdowns for
  dictionaries/encyclopedias and for juvenile belles lettres (PZ5-90) DO [sec. 1, 4, 5].
- Publication-date breakdowns follow the translation's own date [sec. 2].
