  Class a separately published abridgment, summary, synopsis, epitome or condensation of an
  individual work with the original work (unless the schedule provides for abridgments) and
  base its book number on the original's book number.

## Applies when
- The resource is a separately published abridgment of an individual work: a reduced form produced by condensation and omission that retains the general sense and unity of the original. Summary, synopsis, epitome and condensation are synonyms.
- Not an adaptation (a rewritten form modified for another purpose or use, such as a simplification for juvenile readers or a change in form from fiction to drama); adaptations are not covered here.
- Not a collection of abstracts (see F 480).

## Rules
1. Explicit provisions for abridgments. If the schedule has explicit provisions for abridgments, follow those provisions. For example, class abridgments of the Bible in BS418, which has the caption Epitomes. Summaries. [sec. 1]
2. No explicit provisions. If the schedule does not have explicit provision for abridgments, class abridgments with the original work. The book number of the abridgment should be based on the book number of the original work, and should normally not be independently formulated. [sec. 2]
3. No original call number. If there is no complete LC call number for the original work (e.g., the abridgment is received before the original), use a class number and Cutter appropriate for the original work. [sec. 3]
4. Shelflisting. For shelflisting of abridgments, see G 65. [sec. 4]

## Examples
Schedule with explicit provision for abridgments [sec. 1]:
Abridgments of the Bible are classed in BS418 (caption: Epitomes. Summaries.)

## Pitfalls
- An adaptation (rewritten for a different purpose or audience, or changed in form) is not an abridgment and is not classed by this chapter. [Background]
- Do not formulate the abridgment's book number independently; derive it from the original's book number. [sec. 2]
- Schedule provisions for abridgments override the general rule of classing with the original. [sec. 1]
