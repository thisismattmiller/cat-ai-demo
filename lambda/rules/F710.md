## Applies when

- The item is computer software with a bibliographic record in the COMPUTER FILES format (not a book with accompanying software in the BOOKS format), or a work about an individual computer program.

## Rules

1. Classification. Class an item of software in the same number in which a book about that software would be classed. [sec. 1]
   - If a particular schedule has a provision of the type "Special programs, A-Z," class software in that number. In most other cases, class software in the number for "Data processing" or its equivalent under the topic in question, if one exists.

2. What is included in the class number. Assign only the $a subfield, not the $b subfield, of the 050 field, i.e., assign only the classification number, not the book number. [sec. 2]

3. Include Cutter numbers for topics, places and persons. Assign as specific a number as is already established and printed in the classification schedules, including Cutter numbers for topics, place, or persons if they are already printed in the schedule. Supply Cutter numbers for places or individuals if the caption in the schedule reads, for example, "By region or country, A-Z," or "Individual, A-Z," and printed Cutter numbers are not present. Do not assign spans of numbers or Cutters. [sec. 3]

4. Specific topic not yet established. If the specific topic has not been established, submit a proposal to establish it in the normal manner. [sec. 4]

(The chapter contains no call-number examples.)

## Pitfalls

- Applies only to records in the computer files format; a book with accompanying software is classed as a book (BACKGROUND).
- No $b book number for software [sec. 2]; but printed or supplied topic/place/person Cutters that form part of the class number are included in $a [sec. 3].
- Prefer a "Special programs, A-Z" caption over the "Data processing" number when the schedule offers one [sec. 1].
