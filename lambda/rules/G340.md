  How to build the Cutter for a criticism or commentary on an individual work: take the original
  work's call number, append the digit 3 to the Cutter that represents the original, then add a
  second Cutter or further digits for the commentary's 1XX/245; the same applied recursively for
  criticism of a criticism.
---

## Applies when
- The work criticizes, comments on, or analyzes another individual work (a subject heading of the form "Author. Title" or "Corporate body. Title" is present), and the schedule gives no special instructions for commentaries.
- The original work's call number is known (in LC's collections), or can be constructed as if it were.
- The work is a criticism of a criticism.
- For classification (which number the commentary goes in) see F 570; for commentaries on works of individual literary authors see F 632; for commentaries about conferences, congresses, meetings, etc., see G 230 sec. 7. This card covers shelflisting only.

## Rules
1. General rule. Unless special instructions are provided in the classification schedules, follow successive Cuttering practices for subarranging separate works by an individual author or corporate body. [sec. 1]
   - Until 2013, if a corporate body was considered the creator of the original work, the commentary on that original work was assigned the same call number as the original work followed by the term Suppl. (cf. G 220). This is no longer done. [sec. 1 note]
2. Criticism/commentary on the first Cutter number. Assign the same call number to the criticism/commentary that was assigned to the original text in the original language, plus the digit 3. Assign a second Cutter for the 1XX and/or 245 fields. Pattern: original `CLASS .X## date` becomes `CLASS.X##3 $b Y## date`. [sec. 2]
3. Criticism/commentary on the second Cutter. Assign the same call number to the criticism/commentary that was assigned to the original text in the original language, plus the digit 3. Add a digit or digits to represent the 1XX and/or 245 fields. Pattern: original `CLASS.X## $b Y## date` becomes `CLASS.X## $b Y##3# date`. [sec. 3]
4. Criticism of original work not in LC collections. [sec. 4]
   - a. Criticism on first Cutter: if the original work would appear as part of the first Cutter, assign the Cutter number (as it would have been assigned to the original) and add the digit 3. Double Cutter based on the 1XX and/or 245 fields. [sec. 4.a]
   - b. Criticism on second Cutter: if the original work would appear as part of the second Cutter, apply the same procedures described in sec. 3. [sec. 4.b]
5. Criticism/commentary of a criticism/commentary. Cutter for the original criticism. Add the digit 3 for the second criticism and add a digit for the 1XX and/or 245 fields of the second criticism. [sec. 5]
6. The base is always the call number of the original text in the original language (not of a translation). [sec. 2, 3]

## Examples
Criticism on the first Cutter: original work with a single Cutter; commentary = same Cutter + 3, then a second Cutter for the commentator [sec. 2]:
```
original work:
  Main entry: Bournonville, August, 1805-1879.
  Title/date: Études chorégraphiques ... 1861.
050 00 $a GV1788 $b .B6 1861

criticism:
  Main entry: Brun, Erik, 1928-1986.
  Title/date: Bournonville and ballet technique : studies and comments on August Bournonville's Études chorégraphiques ... [1961]
050 00 $a GV1788.B63 $b B78 1961
```

Criticism on the first Cutter, where the criticism also contains the complete text of the original [sec. 2]:
```
original work:
  Main entry: Edwards, Jonathan, 1703-1758.
  Title/date: The distinguishing marks of a work of the spirit of God ... 1741
050 00 $a BR520 $b .E35 1741

criticism:
  Main entry: Parrish, Archie, 1932-
  Title/date: The spirit of revival : discovering the wisdom of Jonathan Edwards / Archie Parrish and R.C. Sproul ; with the complete, modernized text of The distinguishing marks of a work of the Spirit of God ... 2000.
  Subject heading: Edwards, Jonathan, 1703-1758. Distinguishing marks of a work of the Spirit of God.
  Additional access point: Edwards, Jonathan, 1703-1758. Distinguishing marks of a work of the Spirit of God.
050 00 $a BR520.E353 $b P37 2000
```

Criticism on the first Cutter [sec. 2]:
```
original work:
  Main entry: Cooper, George E.
  Title/date: History of scientific theories and ... 1984.
050 00 $a Q125 $b .C67 1984

criticism:
  Main entry: Brown, Robert C.
  Title/date: A critical analysis of History ... 1986.
  Subject heading: Cooper, George E. History of scientific theories and ...
050 00 $a Q125.C673 $b B76 1986
```

Criticism on the first Cutter where the original is entered under a corporate body (no "Suppl." since 2013) [sec. 2]:
```
original work:
  Main entry: Catholic Church. Pope (2005-2013 : Benedict XVI)
  Title: Caritas in veritate ... 2005.
050 00 $a BV4639 $b .C3226 2005

criticism:
  Main entry: González-Carvajal Santabárbara, Luis.
  Title: La fuerza del amor inteligente ... 2009.
  Subject heading: Catholic Church. Pope (2005-2013 : Benedict XVI). Caritas in veritate.
050 00 $a BV4639.C32263 $b G66 2009
```

Criticism on the second Cutter: original's second Cutter + 3 + digit(s) for the critic [sec. 3]:
```
original work:
  Main entry: Arendt, Hannah, 1906-1975.
  Title/date: Eichmann in Jerusalem ... [1963]
050 00 DD247.E5 $b A7 1963

criticism:
  Main entry: Parvikko, Tuija.
  Title/date: Arendt, Eichmann, and the politics of the past ... 2008.
  Subject heading: Arendt, Hannah, 1906-1975. Eichmann in Jerusalem.
050 00 DD247.E5 $b A737 2008
```

Criticism of a criticism: first criticism's Cutter + 3 + digit for the second critic [sec. 5]:
```
original work:
  Main entry: Asanga.
  Title/date: Abhisamayalankara ... [1972]
050 00 $a BQ1955 $b .A8 1972

original criticism:
  Main entry: Tson-kha-pa Blo-bzan-grags-pa, 1357-1419.
  Preferred title: Legs bsad gser phren
  Title/date: Ses rab kyi pha rol ... [1977]
  Subject heading: Asanga. Abhisamayalankara.
050 00 $a BQ1955.A83 $b T76 1977

criticism of criticism:
  Main entry: Blo-gros-rgya-mtsho.
  Title/date: Dran ba dan nes pai ... [1982]
  Subject heading: Tson-kha-pa Blo-bzan-grags-pa, 1357-1419. Legs bsad gser phren.
  Subject heading: Asanga. Abhisamayalankara.
050 00 $a BQ1955.A83 $b T7633 1982
```

## Pitfalls
- Special instructions in the classification schedule override this general procedure. [sec. 1]
- The "3" is appended to the Cutter representing the original work, wherever that Cutter sits: to the first Cutter when the original has one Cutter (`.B6` -> `.B63`), to the second Cutter when the original has two (`A7` -> `A73`). [sec. 2, 3]
- When the original is on the first Cutter, the commentator gets a new second Cutter; when the original is on the second Cutter, the commentator gets additional digit(s) on that same Cutter, never a third Cutter. [sec. 2, 3]
- Base the number on the original text in the original language, not on a translation. [sec. 2, 3]
- The original need not be in LC's collections: construct the Cutter the original would have received and then add 3. [sec. 4]
- Corporate-body originals no longer take "Suppl." for commentaries (pre-2013 practice; cf. G 220). [sec. 1 note]
- In the criticism-of-criticism example, the second-level digit for the new critic is added after the 3 (`T76` -> `T763` -> `T7633`). [sec. 5]
