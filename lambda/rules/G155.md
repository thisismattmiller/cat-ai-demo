## Applies when

- The resource is a separately issued subordinate work that continues or complements a previously issued work: a supplement, appendix, index, addendum, etc. (cf. F 720), and is being cataloged as a separate item.
- The resource is a separately cataloged index to a monograph or serial.
- A supplement is described only in the physical description area (300 field) of the original work's record, and a call number is needed for the supplementary piece.

## Rules

1. [sec. 1.a] **Supplements cataloged separately, general rule.** Formulate the call number for the supplementary work by using the call number of the original work (including the date, if any) and adding the designation `Suppl.`
2. [sec. 1.b] **Call number for original work not available.** If the complete call number for the original work is not available (e.g., the original is held in microfiche only, or the supplement is received before the original), formulate the call number for the supplementary work by using the Cutter number that would be used for the expected original work and adding the designation `Suppl.` Do not add a date to the call number of the later supplement if the date of the original work is not known. If the original work is later received, the call number on the supplement is changed in order to add the date of the original work to the call number of the supplement.
3. [sec. 1.c] **Multiple supplements for the same work.** If more than one supplement is issued to a particular work, add successive numbers, beginning with the number 2, to the designation, e.g., `Suppl.`, `Suppl. 2`, `Suppl. 3`, etc.
4. [sec. 1.d] **Supplements to a numbered volume of a series.** In the case of a work that supplements a particular numbered volume of a series, provide the pertinent volume number as part of the complete call number, e.g. `HD28.Y555 vol. 55 Suppl.`
5. [sec. 1.e] **Supplements to serials.** If a monograph or serial (with the exception of indexes) is issued as a supplement to a serial, treat both publications as two distinct works (i.e., no `Suppl.` designation; the supplement gets its own call number). However, if a monograph or serial is issued as a supplement to a monograph, treat the supplement as described in sec. 1.a–d.
6. [sec. 2] **Supplements covered by a statement in the physical description area.** If a supplement is covered by a statement in the physical description area (300 field), assign the call number of the original work with added identification such as `Tables`, `Maps`, etc. to the supplementary work. The designation is added only to the call number in the book and the item record. If there is no identifying word used in the supplementary note, use the term `Suppl.` as the designation in the call number in the book and item record. Do not use any designation in the call number on the bibliographic record (050).
7. [sec. 3] **Indexes cataloged separately.** Add `Index` to the call number of separately cataloged indexes to monographs and serials. If more than one index is issued to a particular work, add successive numbers, beginning with the number 2, to the designation, e.g., `Index`, `Index 2`, `Index 3`, etc.

## Examples

Supplement to a numbered volume of a series; volume number included before the designation [sec. 1.d]:

```
HD28.Y555 vol. 55 Suppl.
```

Supplement (tables) covered by the 300 field of the original; original's call number plus identifying word, on the item only [sec. 2]:

```
Original work:

Main entry:  Archer, Stephen Hunt.
Title/date:  Financial management ... c1983.
Collation:  xix, 764 p. : ill. ; 25 cm. + tables.

050 00 $a HG4026 $b .A745 1983

Call number for supplement:

050 00 $a HG4026 $b .A745 1983 Tables
```

Separately cataloged index to a serial; serial's call number plus Index [sec. 3]:

```
Main entry:  Western Association of Map Libraries.
Title:  Information bulletin ...

050 00 $a GA192 $b.W47

Main entry:  Woodward, Frances M., 1938-
Title/date:  Index to the Information bulletin ... 1983.
Subject:  Western Association of Map Libraries.  Information
Bulletin--Indexes.

050 00 $a GA192 $b .W47 Index
```

## Pitfalls

- A supplement to a *serial* (other than an index) is a distinct work with its own call number, not `<serial call number> Suppl.` [sec. 1.e]. A supplement to a *monograph*, whether the supplement is itself a monograph or a serial, does take the original's call number plus `Suppl.`
- Indexes are the exception to sec. 1.e: an index to a serial takes the serial's call number plus `Index` [sec. 3].
- The designation `Suppl.` follows the full call number of the original *including its date*; if the original's date is unknown, add no date (sec. 1.b).
- Numbering of designations starts at 2 for the second supplement/index (`Suppl.`, `Suppl. 2`; `Index`, `Index 2`); there is no `Suppl. 1`.
- For a supplement covered only by a 300-field statement with no identifying word, `Suppl.` goes on the item/book call number only; the 050 on the bibliographic record carries no designation [sec. 2 note].
- Earlier practices (successive Cutters for serial/monograph supplement pairs; double Cuttering by the person responsible for the supplement) are historical and not the current rule.
